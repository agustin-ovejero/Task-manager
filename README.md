# Task Lab

Laboratorio de pruebas accesible para aprender Playwright con TypeScript. La app usa estado local y `localStorage`; no tiene backend real.

## Arranque

```bash
npm install
npm run dev
```

## Comando playwright
```bash
npm test
npm report
npm report:ui
```
Abre `http://localhost:3000/login`.
